# 例：会議メモ → 議事録

## 入力（会議メモ）

```
10/7 14時 定例 山田 佐藤 鈴木
・新サイトの公開日 → 11/1で決定
・画像差し替え 佐藤さん 来週中
・問い合わせフォームのテスト 鈴木 早めに
・予算の追加は部長に確認してから（次回）
```

## 出力（議事録）

```markdown
# 新サイト定例 議事録

- 日時：2026/10/07 14:00〜【要確認】
- 参加者：山田、佐藤、鈴木
- 記録：【要確認】

## 決定事項
1. 新サイトの公開日を 11/1 に決定。

## ToDo
| # | 内容 | 担当 | 期限 |
|---|---|---|---|
| 1 | トップページなどの画像を差し替える | 佐藤 | 10/16（金） |
| 2 | 問い合わせフォームの送信テストを行う | 鈴木 | 【要確認】 |

## 持ち越し・未決事項
- 予算の追加：部長に確認してから次回判断する（確認担当【要確認】）。

## 議論の要点
- 公開日：11/1 で関係者の作業が間に合うことを確認した。

## 次回
- 【要確認】
```

ポイント：
- 「来週中」は会議日（10/7 水）から計算して「10/16（金）」にした。週の締めを金曜とする社内ルールがなければ【要確認】にする。
- 「早めに」は期限ではないので【要確認】にし、ユーザーに確認する。
