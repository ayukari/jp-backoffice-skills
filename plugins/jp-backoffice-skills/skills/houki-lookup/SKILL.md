# houki-lookup: 法令の条文を公式データから引く

法令の条文は、モデルの記憶ではなく **e-Gov 法令API の公式データ** から取得して示す。記憶の条文は古い（改正前）か、条番号や文言を取り違えることがあるため。

## 手順
1. 法令名と条番号を確認する。
   - 条番号が分からない場合は、法令名だけで検索して候補を示し、どの条を見たいかを確認する。**推測で条番号を決めない**。
   - 「インボイスの義務は何条？」のように条番号を聞かれた場合も、心当たりの条を取得して中身を確認してから答える。
2. スクリプトで条文を取得する。
   ```bash
   python3 ${CLAUDE_SKILL_DIR}/scripts/law_lookup.py --title 消費税法 --article 第57条の4
   python3 ${CLAUDE_SKILL_DIR}/scripts/law_lookup.py --title 消費税法            # 法令の検索のみ
   python3 ${CLAUDE_SKILL_DIR}/scripts/law_lookup.py --law-id 363AC0000000108 --article 30 --json
   ```
   条番号は `30`・`第30条`・`57の4`・`第五十七条の四` のどれでもよい。`--title` は完全一致する法令を優先する（「消費税法」で「消費税法施行令」を取らない）。
3. 取得した条文を **原文のまま** 引用し、そのあとに説明を書く。
4. 回答の最後に、法令名・法令番号・施行日・e-Gov の URL を書く（スクリプトの出力の「出典」行をそのまま使う）。

## ルール
- 条文の文言は、スクリプトの出力以外から書かない。
- スクリプトが終了コード 1 で失敗したら（見つからない・接続できない）、**記憶で条文を補わず**、取得できなかったことをそのまま伝える。ユーザーには e-Gov 法令検索（https://laws.e-gov.go.jp/）で確認するよう案内する。
- 具体的な事案への当てはめは断定せず、弁護士・税理士などの専門家への確認を勧める。
- 施行日（enforcementDate）は「どの時点の条文か」を示す。改正が近い法令では、ユーザーが知りたい時点の条文かどうかに注意する。

## 注意
- e-Gov 法令API は認証不要の公開 API。スクリプトはリクエストの間隔を 0.5 秒以上あけ、User-Agent を付けている。連続で大量に取得しない。
- 社内ネットワークなどで `laws.e-gov.go.jp` に接続できない環境では使えない。その場合は接続許可の設定が必要。
