# 目的別テンプレート

`【】` の中を埋めて使う。相手との関係（社外／社内・目上）に合わせて、挨拶と結びを調整する。
社内向けなら「いつもお世話になっております」を「お疲れ様です」に替える。

---

## 1. 依頼

**件名:** 【ご依頼】【用件】のお願い（【期日】まで）

```
【会社名】
【部署】【氏名】様

いつもお世話になっております。【自社名】の【自分の名前】です。

【用件】について、ご対応をお願いしたくご連絡いたしました。

■ ご依頼内容
・【内容1】
・【内容2】

■ 期日
【月日（曜日）】までにご対応いただけますと幸いです。

ご多忙のところ恐れ入りますが、何卒よろしくお願いいたします。
```

## 2. 催促（リマインド）

**件名:** 【ご確認のお願い】【用件】（【新しい期日】まで）

```
【会社名】
【部署】【氏名】様

いつもお世話になっております。【自社名】の【自分の名前】です。

【元の依頼日】にお願いしておりました【用件】について、その後の状況はいかがでしょうか。
【元の期日】を目安にお願いしておりましたため、念のためご連絡いたしました。

恐れ入りますが、【新しい期日】までにご確認いただけますでしょうか。

なお、本メールと行き違いでご対応いただいておりましたら、ご容赦ください。
引き続きよろしくお願いいたします。
```

## 3. お詫び

**件名:** 【件名】に関するお詫び

```
【会社名】
【部署】【氏名】様

いつもお世話になっております。【自社名】の【自分の名前】です。

このたびは【起きたこと】により、多大なるご迷惑をおかけし、誠に申し訳ございません。

■ 経緯
【何が、いつ、なぜ起きたか（言い訳にならないよう事実のみ）】

■ 対応
【すでに行った対応】

■ 再発防止策
【今後の対策】

重ねてお詫び申し上げます。今後このようなことがないよう努めてまいります。
```

## 4. お断り

**件名:** 【用件】の件につきまして

```
【会社名】
【部署】【氏名】様

いつもお世話になっております。【自社名】の【自分の名前】です。

このたびは【用件】のご提案（ご依頼）をいただき、誠にありがとうございます。
社内で慎重に検討いたしましたが、【理由（簡潔に）】のため、今回は見送らせていただくことになりました。

ご期待に沿えず大変申し訳ございません。
【代替案があれば：〇〇であればご協力できる可能性がございます。】

今後ともよろしくお願いいたします。
```

## 5. お礼

**件名:** 【用件】のお礼

```
【会社名】
【部署】【氏名】様

いつもお世話になっております。【自社名】の【自分の名前】です。

本日は【打ち合わせ／ご対応】の機会をいただき、誠にありがとうございました。
【具体的に良かった点・学んだ点】は、大変勉強になりました。

【次のアクション：いただいた内容をもとに、〇日までに〇〇をお送りいたします。】

今後ともよろしくお願いいたします。
```

## 6. 日程調整

**件名:** 【用件】のお打ち合わせ日程のご相談

```
【会社名】
【部署】【氏名】様

いつもお世話になっております。【自社名】の【自分の名前】です。

【用件】について、【所要時間】ほどお打ち合わせのお時間をいただけますでしょうか。
下記のうち、ご都合のよい日時をお知らせいただけますと幸いです。

・【月日（曜日）】【時間】
・【月日（曜日）】【時間】
・【月日（曜日）】【時間】

上記で難しい場合は、ご都合のよい日時をお知らせください。
形式：【オンライン（URLは確定後にお送りします）／貴社訪問】

よろしくお願いいたします。
```

## 7. 報告

**件名:** 【報告】【用件】の進捗（【日付】時点）

```
【宛名】

お疲れ様です。【自分の名前】です。
【用件】について、【日付】時点の状況をご報告いたします。

■ 結論
【一文で：予定どおり／〇日遅れ見込み など】

■ 完了したこと
・【内容】

■ 今後の予定
・【内容】（【期日】）

■ 課題・ご相談
・【あれば】

以上、よろしくお願いいたします。
```

## 8. 初めての連絡

**件名:** 【用件】のご相談（【自社名】【自分の名前】）

```
【会社名】
【部署】【氏名】様

突然のご連絡失礼いたします。【自社名】の【自分の名前】と申します。
【連絡先を知った経緯：〇〇様からご紹介いただき／貴社のウェブサイトを拝見し】ご連絡いたしました。

【用件を2〜3文で】

ご多忙のところ恐縮ですが、ご検討いただけますと幸いです。
何卒よろしくお願いいたします。

――――――――――
【署名】
```
